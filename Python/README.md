# Python Learning Path

A comprehensive, structured curriculum for learning Python from fundamentals to advanced topics.

## Structure

This repository is organized into sequential modules covering:

- **00-05**: Introduction, Environment & Tools, Fundamentals, Data Types, Type Conversion, Operators
- **06-11**: Control Flow, Strings, Lists, Tuples, Sets, Dictionaries
- **12-17**: Functions, Scope & Namespaces, Comprehensions & Generators, Modules & Packages, File Handling, Exceptions
- **18-23**: OOP, Special Methods, Decorators, Iterators, Context Managers, Functional Programming
- **24-29**: Built-in Functions, Standard Library, Datetime, Regex, JSON/CSV, Type Hints
- **30-35**: Advanced Types, Dataclasses, Pattern Matching, Async Python, Concurrency, Testing
- **36-41**: Debugging & Profiling, Logging & CLI, Packaging, Code Quality, Databases, Networking
- **42-47**: Web Development, Data Processing, Security, Internals, Descriptors & Metaclasses, Advanced Python
- **48-53**: Performance, Architecture & Design, Exercises, Projects, Interview Questions, Cheatsheets

## How to Use

1. Start from `00-introduction` and progress sequentially.
2. Each topic folder is designed to hold notes, examples, and exercises.
3. Use the interview and cheatsheet sections for revision.

Happy learning!
