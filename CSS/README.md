# CSS Learning Path

A comprehensive, structured curriculum for learning CSS from fundamentals to modern layout, architecture, and performance.

## Structure

This repository is organized into sequential modules covering:

- **00-05**: Introduction, Environment & Tools, Syntax, Adding CSS, Selectors, Cascade & Specificity
- **06-11**: Values & Units, Colors, Backgrounds, Box Model, Typography, Display
- **12-17**: Positioning, Overflow, Flexbox, CSS Grid, Responsive Design, Pseudo-classes
- **18-23**: Pseudo-elements, Borders & Shapes, Transforms, Transitions, Animations, CSS Functions
- **24-29**: Custom Properties, Forms & UI, Tables, Images & Media, Layout, Logical Properties
- **30-35**: Modern CSS, Accessibility, Architecture, Methodologies, Preprocessors, Tools
- **36-39**: Performance, Browser Rendering, Debugging, Browser Compatibility
- **40-43**: Exercises, Projects, Interview Questions, Cheatsheets

## How to Use

1. Start from `00-introduction` and progress sequentially.
2. Each topic folder is designed to hold notes, examples, and exercises.
3. Use the interview and cheatsheet sections for revision.

Happy learning!
