# SQL Learning Path

A comprehensive, structured curriculum for learning SQL from fundamentals to advanced database topics.

## Structure

This repository is organized into sequential modules covering:

- **00-05**: Introduction, Database Environment, Relational Concepts, SQL Fundamentals, Data Types, Table Management
- **06-11**: Constraints, INSERT, SELECT Basics, Filtering, Sorting & Limiting, SQL Functions
- **12-17**: Aggregates, Grouping, Joins, Subqueries, CTEs, Set Operations
- **18-23**: CASE Logic, NULLs, Data Modification, Views, Window Functions, Advanced Aggregation
- **24-29**: Schema Design, Normalization, Indexes, Query Performance, Transactions, Concurrency & Locking
- **30-35**: Advanced SQL, JSON, Stored Programming, Triggers, Security, Backup & Recovery
- **36-41**: Application Development, Architecture, Partitioning & Scaling, Observability, SQL Dialects, PostgreSQL
- **42-49**: MySQL, SQLite, Analytics SQL, Data Modeling, Exercises, Projects, Interview Questions, Cheatsheets

## How to Use

1. Start from `00-introduction` and progress sequentially.
2. Each topic folder is designed to hold notes, examples, and exercises.
3. Use the interview and cheatsheet sections for revision.

Happy learning!
