# Bash Scripting Learning Path

A comprehensive, structured curriculum for learning Bash scripting from fundamentals to advanced automation and DevOps.

## Structure

This repository is organized into sequential modules covering:

- **00-05**: Introduction, Environment & Setup, Terminal Fundamentals, Bash Basics, File System, File & Directory Commands
- **06-11**: Output & Input, Redirection, Pipes & Commands, Variables, Quoting, Command Substitution
- **12-17**: Parameters & Arguments, Conditional Statements, Test & Comparison, Loops, Functions, Arrays
- **18-23**: String Manipulation, Parameter Expansion, Globbing, File Searching, Text Processing, Grep
- **24-29**: Sed, Awk, Regular Expressions, Permissions, Processes & Jobs, Background & Foreground
- **30-35**: Exit Status & Error Handling, Bash Options, Process Substitution, Command Execution, Shell Expansion, Arithmetic
- **36-41**: Input Processing, Heredocs, Signals, Trap, Debugging, Environment & Shell Configuration
- **42-47**: History & Completion, Cron & Scheduling, Networking, JSON & Data, SSH & Remote Automation, Git Automation
- **48-54**: System Automation, Security, Portability, Advanced Bash, Internals, Best Practices, DevOps & CI/CD
- **55-58**: Exercises, Projects, Interview Questions, Cheatsheets

## How to Use

1. Start from `00-introduction` and progress sequentially.
2. Each topic folder is designed to hold notes, examples, and exercises.
3. Use the interview and cheatsheet sections for revision.

Happy learning!
