# TypeScript Learning Path

A comprehensive, structured curriculum for learning TypeScript from fundamentals to advanced type-level programming.

## Structure

This repository is organized into sequential modules covering:

- **00-02**: Introduction, Environment & Tools, Fundamentals
- **03-08**: Primitive Types, Arrays & Tuples, Object Types, Type Aliases, Interfaces, Unions & Intersections
- **09-14**: Functions, Type Narrowing, Type Assertions, Enums, Literal Types, Generics
- **15-20**: Keyof/Typeof, Utility Types, Conditional Types, Mapped Types, Template Literals, Recursive & Advanced Types
- **21-26**: Advanced Functions, Classes & OOP, Modules, Declaration Files, JS Interop, tsconfig & Compiler
- **27-32**: Compiler API, Type System Internals, Advanced Patterns, Built-in Types, Async Types, Error Handling
- **33-38**: DOM & Browser, Node.js, Package Management, Testing, Linting, Framework Integration
- **39-41**: Performance, Migration & Large Projects, Advanced TypeScript
- **42-45**: Exercises, Projects, Interview Questions, Cheatsheets

## How to Use

1. Start from `00-introduction` and progress sequentially.
2. Each topic folder is designed to hold notes, examples, and exercises.
3. Use the interview and cheatsheet sections for revision.

Happy learning!
