 ## What is Programming?

 **Programming is the process of giving instructions to a computer so that it can perform a task.**

 Think about a computer like a very fast worker. It can do calculations, store information, display websites, play music, run games, etc. But it doesn't automatically know **what you want it to do**.

 You need to give it instructions.

 Those instructions are written using a **programming language** such as:

 - Python
- Java
- C
- C++
- JavaScript
- C#
- Go
- Rust

 ### A simple real-life example

 Suppose you want to tell a person:

 > "Take two numbers, add them, and tell me the answer."

 The person can understand that sentence directly.

 But a computer needs instructions written in a programming language.

 For example, in Python:

```
a = 10
b = 20

result = a + b

print(result)
```

 The computer follows these instructions:

```
a = 10
↓
Store 10

b = 20
↓
Store 20

a + b
↓
Calculate 30

print(result)
↓
Display 30
```

 Output:

```
30
```

 So, **programming = writing instructions that a computer can follow.**

 ## What is a Program?

 This is an important difference.

 A **program** is a set of instructions written to make a computer perform a particular task.

 For example, a calculator program might contain instructions for:

```
Take number 1
Take number 2
Add them
Show the result
```

 A web browser, calculator, game, mobile app, and operating system are all examples of software created using programs.

---

 ## What is a Programming Language?

 A **programming language is a language that allows humans to communicate instructions to computers.**

 For example:

```
print("Hello World")
```

 is written in **Python**.

 Another language might have different syntax for doing the same thing.

 The important thing to understand is:

 **Programming is the activity.**\
 **A programming language is the tool/language we use to do programming.**

 Think of it like this:

```
Human
  ↓
Programming Language
  ↓
Instructions
  ↓
Computer
  ↓
Result
```

 ## What actually happens when you write code?

 When you write:

```
print("Hello")
```

 the computer doesn't magically understand English or Python directly.

 There is software such as an **interpreter** or **compiler** that translates/processes your code into instructions the computer can execute.

 Very simplified:

```
Your Code
   ↓
Python / Java / C / etc.
   ↓
Interpreter or Compiler
   ↓
Machine Instructions
   ↓
CPU
   ↓
Result
```

 You don't need to understand compilers deeply right now. We'll get there later.

 ## Programming is more than just writing code

 This is something beginners often misunderstand.

 Programming isn't simply:

 > "I need to memorize Python syntax."

 Instead, programming is mainly about **problem solving**.

 For example, imagine the problem:

 > "I have 5 numbers. Find the largest number."

 Before writing code, you need to think:

```
1. Get the numbers
2. Compare them
3. Keep track of the largest number
4. Display the largest number
```

 Then you convert that thinking into code.

 That's why programming is often described as:

 **Problem → Logic → Code → Result**

---

 ## One more important concept: Algorithm

 An **algorithm** is a step-by-step procedure for solving a problem.

 For example, making tea could be described as:

```
1. Take water
2. Boil water
3. Add tea
4. Add milk
5. Add sugar
6. Serve
```

 That's an algorithm.

 Programming is often:

```
Problem
   ↓
Create an algorithm
   ↓
Write code
   ↓
Run the code
   ↓
Get result
```
