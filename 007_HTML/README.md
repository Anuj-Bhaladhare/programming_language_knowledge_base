# HTML Learning Path

A comprehensive, structured curriculum for learning HTML from fundamentals to modern semantic and accessible markup.

## Structure

This repository is organized into sequential modules covering:

- **00-05**: Introduction, Environment & Tools, Document Structure, Elements & Attributes, Text & Content, Links
- **06-11**: Images, Lists, Tables, Forms, Semantic HTML, Div & Span
- **12-17**: Audio & Video, Embedded Content, Head & Metadata, Accessibility, SEO, HTML APIs
- **18-21**: Security, Validation, Modern HTML, Project Structure
- **22-25**: Exercises, Projects, Interview Questions, Cheatsheets

## How to Use

1. Start from `00-introduction` and progress sequentially.
2. Each topic folder is designed to hold notes, examples, and exercises.
3. Use the interview and cheatsheet sections for revision.

Happy learning!
