# JavaScript Learning Path

A comprehensive, structured curriculum for learning JavaScript from fundamentals to advanced topics.

## Structure

This repository is organized into sequential modules covering:

- **00-02**: Introduction, Environment & Tools, Fundamentals
- **03-07**: Values, Types, Variables, Type Conversion, Operators, Control Flow, Strings
- **08-12**: Functions, Scope & Closures, Numbers/Math/Dates, Arrays, Objects
- **13-17**: Built-in Data Structures, Modern JS, This/Prototypes, Classes/OOP, Error Handling
- **18-22**: Debugging, Internals, Async JS, Event Loop, Modules
- **23-27**: Iterators/Generators, JSON, Regex, Web Fundamentals, DOM
- **28-32**: Browser APIs, Networking, Node.js, Package Management, Testing
- **33-38**: Functional Programming, Design Patterns, Performance, Security, Web Workers, WebAssembly
- **39-42**: Exercises, Projects, Interview Questions, Cheatsheets

## How to Use

1. Start from `00-introduction` and progress sequentially.
2. Each topic folder is designed to hold notes, examples, and exercises.
3. Use the interview and cheatsheet sections for revision.

Happy learning!
