# C++ Learning Path

A comprehensive, structured curriculum for learning C++ from fundamentals to advanced systems programming.

## Structure

This repository is organized into sequential modules covering:

- **00-05**: Introduction, Environment & Tools, Fundamentals, I/O, Data Types, Variables & Constants
- **06-11**: Type Conversion, Operators, Control Flow, Functions, Arrays, Strings
- **12-17**: Pointers, References, Memory Management, Structs/Enums/Unions, Classes & Objects, OOP
- **18-23**: Operator Overloading, Inheritance & Polymorphism, Copy/Move Semantics, Smart Pointers, Namespaces, Preprocessor
- **24-29**: Templates, Concepts, STL Overview, Sequence Containers, Associative Containers, STL Algorithms
- **30-35**: Iterators & Ranges, Functional C++, Exceptions, File Handling, Standard Library, Modern C++
- **36-41**: Coroutines, Concurrency, Memory Model, Compilation & Linking, Build Systems, Debugging
- **42-47**: Testing, Performance, Undefined Behavior, Low-Level C++, Networking, Security
- **48-55**: Design Patterns, Metaprogramming, Advanced Features, Internals, Exercises, Projects, Interview, Cheatsheets

## How to Use

1. Start from `00-introduction` and progress sequentially.
2. Each topic folder is designed to hold notes, examples, and exercises.
3. Use the interview and cheatsheet sections for revision.

Happy learning!
